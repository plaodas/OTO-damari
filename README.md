# OTO溜まり

吹くと青いノイズ粒が流れ、夜光虫のような光と音が呼応する WebGL2 / WebAudio MVP です。WebGL2 必須です。half-float の速度場が使えない端末では、粒子は従来の漏斗式で動きます。

## 起動

```bash
npm install
npm run dev
```

表示された URL をブラウザで開き、最初に画面をタップしてください。タップをきっかけに WebAudio を有効化し、マイク使用許可を求めます。同じタップで粒子への衝撃と共鳴音も発生します。

## 操作

| 操作 | 音 | 粒子の反応 |
| --- | --- | --- |
| 弱い吹き | ソルフェジオ共鳴音 | ふわっと光る |
| 中くらいの吹き | ソルフェジオ共鳴音 | 流れ始め、水面が光る |
| 強い吹き | 174 / 285 / 963 Hz の和音（吹き続けているあいだ） | 高速で流れて光の帯になる |
| タップ | ソルフェジオ共鳴音 | 周囲の粒子が弾ける |
| スワイプ | ソルフェジオ共鳴音 | 強吹き相当の約 50% の勢いで流れる |
| シェイク | ソルフェジオ共鳴音 + キラッ | 縦 3 段の菱形が対流する |
| 左下の丸 | — | 撮った像の暗い部分ほど粒子が密に集まり、被写体が点描として浮かぶ |
| 撮影完了 | ソルフェジオ共鳴音 + キラッ | 点描が集まり、約 5 秒でほどける |
| 右下の丸 | — | 音量を調整する |
| 傾ける | — | 静止姿勢からの傾き方向へ、ゆっくり漂う |
| 北を向く | 範囲に入った瞬間にソルフェジオ共鳴音 | 吹いていないあいだ粒が上へ流れ、芯は赤白、外周は赤になる |

- 吹く強さが 1 または 2 に上がった瞬間に共鳴音が鳴ります。強い吹き（レベル 3）のあいだは 174 / 285 / 963 Hz の和音が流れ続け、弱まると消えます
- タップ、スワイプ、シェイク、弱い／中くらいの吹き、撮影、北向きへの進入では、174〜963 Hz の 9 音が控えめな共鳴音として順番に巡ります。前の音は残したまま最大 5 音まで重なります。音響演出であり、医療・治癒効果を意図したものではありません
- マイクを拒否すると吹きかけ検出だけが無効になり、粒子表示とタップ操作は継続します
- カメラ画像は低解像度化して端末のメモリ内だけで解析します。アップロード、ファイル保存、Web Storage への保存は行わず、撮影または「閉じる」の直後にカメラを停止します
- カメラを開くと TensorFlow.js の MiDaS v2.1 small と人物マスクを読み込みます。粒子は輪郭線ではなく、写真の暗い部分ほど密な点描として集まります。人物がいれば背景は捨てます。モデルが読めない端末では輝度だけで点描します
- カメラ画面の「消す」で写真由来の粒子配置を解除できます。集め終わると約 5 秒で自然にほどけます
- 端末が北を向くと、吹いていないあいだ粒が画面の上へ流れます。方位はコンパス（地磁気）で、最初の画面タップ後に有効になります。PC や HTTP（localhost 以外）では反応しません。Android の Brave など、シールドでセンサーを止めるブラウザでは Chrome より効きにくいことがあります

## 描画と品質

- 粒子は Transform Feedback で GPU 更新します。見た目は海中のプランクトン寄せで、スマホ約 900、PC 約 1,400 粒です
- 速度場は短辺 128、スマホ上限 192、PC 上限 256 の RGBA16F（`EXT_color_buffer_float`）です。Jacobi はスマホ 8 回、PC 16 回程度です
- `devicePixelRatio` とフレーム時間を見て格子と Jacobi 回数を落とします
- `gl_PointSize` 上限が小さい端末だけ、point sprite の代わりに instanced quad で描きます

## スマホで確認する場合

`getUserMedia` はセキュアコンテキストでのみ利用できます。PC の `localhost` は利用できますが、同一 LAN 上のスマホから `http://PCのIPアドレス:5173` を開く方法では、多くのブラウザでマイクが許可されません。HTTPS で配信するか、HTTPS 対応の開発トンネルを利用してください。

端末スピーカーの音をマイクが拾うと再反応することがあります。実機調整時はイヤホンを使うか、`main.js` の RMS 閾値を端末に合わせて調整してください。

コンソールから吹きレベルを模擬できます。

```js
__otoSetLevel(1) // 弱い吹き（共鳴音）
__otoSetLevel(2) // 中くらいの吹き（共鳴音）
__otoSetLevel(3) // 強い吹き（174 / 285 / 963 Hz の和音）
__otoSetLevel(null) // マイク入力へ戻す
```

## ホーム画面に追加（PWA）

HTTPS で開いたあと、ホーム画面に追加するとブラウザのアドレスバーと下部ツールバーが消えて全画面表示になります。Safari や Chrome のタブとして開いているあいだは、バーは残ります。

- iPhone / iPad（Safari）: 共有 → ホーム画面に追加
- Android（Chrome）: メニュー → アプリをインストール / ホーム画面に追加

アイコンから起動すると `standalone` 表示になります。iPhone のホームインジケータと時刻・電池のステータスバーはシステムの一部なので残ります。

粒子の位置と速度は GPU バッファで ping-pong します。描画は WebGL2 の point sprite（または instanced quad）と生成ノイズテクスチャを使用し、`gl.ONE, gl.ONE` の加算合成で発光させています。強吹き時だけ 1 フレーム遅れの位置で短い光跡を `gl.LINES` で重ねます。マイク RMS とスワイプは速度場への splat、漏斗は場への外力、シェイクは渦です。弱い／中くらいの吹き、タップ、スワイプ、シェイク、撮影、北向きの音はソルフェジオ共鳴音です。強い吹きは 174 / 285 / 963 Hz の持続和音、シェイクと撮影完了は共鳴にキラッを重ねます。
